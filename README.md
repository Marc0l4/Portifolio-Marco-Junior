# Portfólio — Marco Francisco de Oliveira Junior

Site pessoal desenvolvido para apresentar meus projetos, minha stack e formas de contato. O visual segue uma estética de terminal/git log, remetendo ao meu foco em desenvolvimento backend.

🔗 **Deploy:** (https://portifolio-marco-junior.vercel.app/)
📎 **LinkedIn:** [linkedin.com/in/marco-junior-7781472a8](https://www.linkedin.com/in/marco-junior-7781472a8/)

---

## Sobre o projeto

O portfólio reúne:

- **Hero** com apresentação rápida em estilo terminal (`$ whoami`)
- **Sobre** com um resumo da minha trajetória
- **Stack** com as tecnologias que utilizo
- **Projetos em produção**, exibidos em janelas de navegador com preview ao vivo (iframe) dos apps hospedados na Vercel
- **Repositórios**, listados em formato `git log --oneline` para os projetos que ainda não têm deploy
- **Contato**, com e-mail, GitHub e LinkedIn
